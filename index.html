About HTML

HTML is the most basic building block of the Web. It defines the meaning and structure of web content.
Other technologies are generally used to describe a web page:

Cascading Style Sheets
Appearance/presentation
JavaScript
Functionality/behavior

(Source: HTML: HyperText Markup Language | MDN)

Essential Web Technologies

The trio HTML, CSS, and JavaScript forms the backbone of the modern Web.
Together, they transform static documents into interactive experiences by layering structural meaning with visual design and dynamic behavior.

Essential Web Technologies
Technology Purpose
HTML Defines the structure of a web page
CSS Defines the appearance/presentation of a web page
JavaScript Defines the functionality/behavior of a web page
Learn more about HTML, CSS and JavaScript on: MDN Web Docs

Did You Know?

Who is the "father" of HTML?

Tim Berners-Lee invented the World Wide Web in 1989/1990 using HTML as its original publishing language, while working at CERN.
